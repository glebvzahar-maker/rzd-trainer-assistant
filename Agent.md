# Ассистент тренера — Корпоративный университет РЖД

## Роль

Я — цифровой помощник тренера, предназначенный для поддержки проведения образовательных мероприятий в Корпоративном университете РЖД. Моя основная задача — помогать в организации и проведении тренингов для руководителей различных производственных вертикалей компании РЖД.

## Основные функции

### 1. Подбор разминок и ледоколов
- Классификация разминок по времени проведения (утро, после обеда, вечер/рефлексия)
- Фильтрация по типу активности (энергизирующие, сплочение, коммуникация, внимание, творческие, профессиональные)
- Рекомендации по длительности и количеству участников
- Указание необходимых материалов для подготовки

### 2. Структурирование образовательных мероприятий
- Помощь в построении тренингов по циклу Колба (проблематизация → дидактика → отработка)
- Соотношение теории и практики 30:70
- Оптимальная последовательность блоков
- Тайминг активностей

### 3. Интерактивные инструменты
- Таймер проведения разминок
- Чек-лист подготовки материалов
- Пошаговые инструкции для ведущего
- Бизнес-связки для обсуждения с участниками

## Целевая аудитория

- Руководители компании РЖД различных производственных вертикалей
- Взрослая аудитория с опытом работы
- Группы от 8 до 25 человек

## Методология

### Цикл Колба
1. **Проблематизация** — выявление актуальной проблемы через разминку или кейс
2. **Дидактика** — теоретический блок (30% времени)
3. **Отработка** — практические задания (70% времени)

### Принципы подбора разминок

| Время | Тип активности | Цель |
|-------|-------------|------|
| Утро (9:00-10:00) | Энергизирующие, знакомство | Взбодрить, создать атмосферу |
| После обеда (14:00-15:00) | Активные, подвижные | Вернуть энергию, переключить |
| Вечер/рефлексия (16:00+) | Сплочение, рефлексия | Подвести итоги, закрепить |

### Категории разминок

1. **Энергизирующие** — повышают активность, снимают усталость
2. **Сплочение** — укрепляют командный дух, доверие
3. **Коммуникация** — развивают навыки общения, слушания
4. **Внимание** — тренируют концентрацию, память
5. **Творческие** — активизируют креативное мышление
6. **Профессиональные** — привязаны к железнодорожной тематике РЖД

## Текущее состояние лендинга

`index.html` — одностраничный лендинг на чистых HTML/CSS/JS без сборки и зависимостей.

**76 активностей:** 22 из материалов РЖД, 28 из книг (15 Кипниса + 13 Еремеевой),
16 из мировой практики и **10 инструментов фасилитации**.
**Распределение по времени:** утро 24, после обеда 26, вечер/рефлексия 26.
**Разминки** — 66, средняя длительность 8 мин. **Инструменты фасилитации** — 10,
средняя длительность 41 мин: это полноценные мероприятия, а не разминки.

Каждое упражнение хранится в массиве `exercises`. Поля делятся на четыре группы.

**Идентификация и классификация**

| Поле | Значение |
|---|---|
| `id` | 1…66, сквозной, не переиспользуется |
| `source` | `rzd` \| `kipnis` \| `eremeeva` \| `world` \| `facilitation` — подпись в карточке и счётчики |
| `name` | уникальное название |
| `time` | `morning` \| `afternoon` \| `evening` |
| `format` | `ledokol` \| `energizer` \| `reflection` \| `activity` \| `facilitation` — таксономия М. Кипниса плюс фасилитация |
| `intensity` | 1 \| 2 \| 3 — физическая и эмоциональная нагрузка |
| `contact` | `true`, если упражнение предполагает тактильный контакт |
| `group` | `small` (8–12) \| `medium` (12–20) \| `large` (20+) |
| `types` | подмножество `energy`, `team`, `comm`, `focus`, `creative`, `pro` |
| `duration` | 3…30 мин для разминок, до 180 мин для инструментов фасилитации |

**Содержание**

`description`, `steps[]`, `materials[]`, `purpose`, `business`

**Метаданные ведущего** — добавлены, чтобы инструмент был пригоден для реального проведения

| Поле | Зачем |
|---|---|
| `context` | контекст, легенда, притча или преамбула: то, что тренер говорит **до** инструкции. Есть у 16 активностей |
| `tip` | что на самом деле делает упражнение рабочим, и где оно ломается |
| `adapt` | как провести при другой численности группы |
| `safety` | обязательное требование; есть у 18 упражнений с движением и контактом |
| `answerKey` | ключ ответов; есть у 6 упражнений, которые иначе невозможно проверить |
| `takeaway` | что участник уносит с собой — обоснование выбора для мотивированной группы |
| `audience` | `any` — состав группы по полу не важен; `mixed` — в однородной группе контакт нужно заменить |
| `audienceNote` | чем заменить контакт в группе из одних женщин или одних мужчин |

### Правила содержания

- `takeaway` формулируется от лица участника, а не от лица тренера
- `business` — профессиональная релевантность для РЖД, без общих слов вроде «команда важна»
- Реальный огонь, открытое пламя и движение с закрытыми глазами в большой группе недопустимы
- Для викторин `answerKey` обязателен: упражнение без ключа тренер не проведёт
- Состав аудитории задаётся полем `audience`: `any` — по умолчанию, `mixed` —
  в однородной группе контакт нужно заменить, и тогда обязателен `audienceNote`.
  Признак «контакт» ставится по факту касаний между участниками, а не по
  наличию упражнения в списке контактных
- `safety` обязателен при `intensity: 3` и при `contact: true`
- Упражнение с `context` не начинают с инструкции: сначала контекст, иначе оно не работает
- Для `format: facilitation` обязательны `context` или `answerKey` с описанием метода:
  тренер должен иметь под рукой определение, а не только название
- Только русский язык; латиница допустима в обозначениях и названиях источников
- Тире — « » с пробелами, многоточие — знак `…`, кавычки — « »

### Правила синхронизации

Каталог `Активности_для_лендинга.md` **генерируется из данных лендинга**, а не ведётся вручную.
Правки вносятся только в массив `exercises` в `index.html`, после чего выполняется:

```bash
python3 .build_catalog.py    # пересобрать .md-каталог из данных лендинга
python3 .verify_sync.py      # проверить, что .md точно соответствует лендингу
```

Служебные файлы (скрытые, не для публикации):
- `.facilitation.py` — источник метаданных ведущего; ключи — названия упражнений
- `.merge_facilitation.py` — вливает метаданные в `index.html`; идемпотентен, добирает только недостающие поля,
  **но `answerKey` перезаписывает всегда**: ключ ответов берётся из `.facilitation.py`, поэтому инструкция
  и ключ не могут разойтись. Правку ключа в `index.html` вручную делать не нужно — она будет затёрта
- `.validate_extract.py` + `validate.js` — извлечение массива и проверка целостности данных
- `.build_catalog.py` — генератор Markdown-каталога
- `.verify_sync.py` — построчная проверка соответствия каталога лендингу
- `.build_icon.py` — геометрия иконки (паровоз) и генерация SVG/PNG из одного описания
- `.inject_icon.py` — встраивает набор иконок в `<head>` как data URI; идемпотентен
- `.verify_contrast.py` — статическая проверка тем: жёсткий цвет без переопределения, градиенты в солнечной теме, токены во всех трёх темах, отсутствие `prefers-color-scheme`, наличие переключателя и инлайн-скрипта

Порядок при изменении текста упражнения: правка `index.html` → `.build_catalog.py` → `.verify_sync.py`.
Порядок при изменении метаданных: правка `.facilitation.py` → `.merge_facilitation.py` → `.build_catalog.py` → `.verify_sync.py`.
Порядок при изменении контекстов и фасилитации: правка `.facilitation_tools.py` → `.merge_tools.py` → `.build_catalog.py` → `.verify_sync.py`.

Правка ключа ответа: **только** `.facilitation.py` → `.merge_facilitation.py` → `.build_catalog.py` → `.verify_sync.py`.
Ключ ответов лежит в `.facilitation.py`; в `index.html` он приводится скриптом в соответствие автоматически.

### Темы оформления

Три темы, переключаются кнопками в шапке. Выбор сохраняется в `localStorage`
(ключ `rzd-trainer-theme`); пока выбор не сделан, тема следует за системной
настройкой и меняется вместе с ней.

| Тема | `data-theme` | Для чего |
|---|---|---|
| Светлая | `light` | обычная работа в помещении |
| Для солнца | `contrast` | яркий свет, улица, проектор: чистый чёрный на белом |
| Тёмная | `dark` | работа вечером и в тёмном помещении |

Технические требования:

- Тема задаётся **только** атрибутом `data-theme` на `<html>`, а не `prefers-color-scheme`.
  Media query не может выразить «пользователь выбрал светлую, а система тёмная»,
  поэтому ручной выбор там не работал бы
- Инлайн-скрипт в `<head>` ставит `data-theme` **до первой отрисовки**, иначе при
  каждой загрузке в тёмной теме видна вспышка светлой палитры
- Значение `<meta name="theme-color">` синхронизируется с темой
- В солнечной теме запрещены градиенты: они выцветают под прямым светом.
  Только сплошные заливки и рамки
- Жёсткий цвет допустим только при наличии переопределения в тёмной теме
- Белый текст на токенном фоне запрещён: в тёмной теме акценты светлеют.
  Использовать `--on-accent`, `--on-primary`, `--on-success`, `--on-secondary`

### Требования к доступности

Проверяются автоматически: axe-core в трёх темах и в открытой карточке —
0 нарушений; контраст всех текстов не ниже 4.5:1 — минимум 4.62:1 в солнечной теме.

- Карточки — настоящие `<button>`, доступны с клавиатуры
- Модальное окно — `role="dialog"`, `aria-modal`, ловушка фокуса, возврат фокуса
- Контраст всех текстов не ниже 4.5:1; это же касается градиентных заголовков карточек, которые axe не измеряет
- `Escape` закрывает карточку, а вне карточки — сбрасывает фильтры; `/` фокусирует поиск
- `prefers-reduced-motion` отключает анимации
- Тёмная тема через `prefers-color-scheme`; в ней светлые акценты требуют тёмного текста

## Инструменты для тренера

Лендинг закрывает рабочий цикл подготовки к занятию:

- **Подбор** — фильтры по времени, источнику, формату, типу, длительности, размеру группы,
  составу аудитории и наличию контакта;
  поиск идёт по названию, описанию, цели, бизнес-связке, шагам, материалам и подсказке ведущему;
  состояние фильтров живёт в адресной строке, поэтому подборку можно дать ссылкой
- **Сценарий** — подборка упражнений под конкретное занятие с суммарным таймингом,
  экспортом в текст и печатью; сохраняется в браузере. Название упражнения в списке
  открывает инструкцию
- **Проведение** — таймер с неблокирующим уведомлением и звуком, чек-лист подготовки с
  сохранением отметок. Отсчёт идёт от абсолютного дедлайна: переживает перезагрузку,
  не сбивается в фоновой вкладке, дублируется в заголовке вкладки и в липкой шапке
  открытой карточки
- **Передача** — копирование инструкции по упражнению целиком, включая контекст и ключ ответов;
  отдельный лист для печати: сценарий и карточка упражнения печатаются своими листами
  (обычная печать каталога не изменилась)
- **Избранное** — отметки «☆ В избранное» в карточке собираются в панели над каталогом,
  сохраняются в браузере и видны на карточке в каталоге
- **Контекст** — легенда, притча или определение метода показываются в карточке до инструкции:
  именно с них тренер начинает, поэтому в каталог попадает всё, что в источнике есть
